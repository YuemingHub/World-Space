## 1. 为什么不再扩张

2026-09-19 的供应侧审判实测出一个事实：

```text
推荐事实的保质期只有 8–12 天。
```

具体证据（`docs/CAPABILITY_SUPPLY_BASELINE_20260919.md` §5，每条带官方 URL 与行号）：

| 条目 | 记录的主张 | 2026-09-19 的现实 |
|---|---|---|
| 稿定设计 | "免费模板够用" | 可下载的免费模板仅限公益模板；无水印与商用授权要会员 |
| 豆包 | 无保留的"免费" | 与现状不符 / 依据不足 |
| 醒图 | "免费修图…消除路人都能做" | 同上 |
| DeepSeek | 旧按钮名「深度思考 / 联网搜索」 | 按钮名已不是这个说法 |

而这批主张在 `resources.json:4` 里被记为 **09-07 "free tiers confirmed"**。

结论：

> **"曾经核实过"不等于"今天仍然成立"。**
> 一个大而全、靠人工周期性复核的目录，注定追不上这个速度。
> 所以在机制解决之前，不继续建设大而全资源目录。

## 2. 任何供应信息必须带的四个字段

今后任何一条对外可见的供应信息（含新增、修改、重新发布），必须同时有：

```text
checked_at            这次核实的具体日期，不是"最近"
source                官方 URL 或官方页面；二手来源要写明是二手
freshness assumption  凭什么认为它到哪天之前还成立（建议：面向普通人的免费/额度类主张 ≤ 30 天）
recheck trigger        什么情况下必须立刻重查（改版、改名、涨价、下架、额度调整、用户报告打不开）
```

四字段缺一：

> **不得对外发布，也不得引用。**

建议写入 Lab 的证据纪律：

```text
面向普通人的"免费 / 额度 / 按钮名 / 页面状态"类主张，
超过 30 天不得再对外引用。
```
