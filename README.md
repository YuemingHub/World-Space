# World Space

> 我们不制造能力，我们寻找世界上已经存在的最好能力，然后帮助普通人知道：我想做这件事，该从哪里进去、怎么开始、怎么把它做出来。

**公开入口：https://ymai.fun**

---

## 这是什么

World Space 帮助普通人找到并使用世界现有优秀能力，把一个想法真正开始做起来。

打开 ymai.fun，从新手村开始，几分钟就能动手。

---

## 怎么用

| 关卡 | 工具 | 做什么 |
|---|---|---|
| 新手村 | 豆包 | 跟 AI 聊两句 |
| 第一关 | 扣子 | 做网站 / PPT / 文章 |
| 第二关 | DeepSeek | 查资料、找答案 |
| BOSS关 | Stirling PDF / WorkBuddy | 处理 PDF / 自动化 |

国产工具优先，国外工具作为进阶备选。
