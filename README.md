# World Space

> 从零开始把 AI 用起来：4 步，每一步都做成一件真事。

**公开入口：https://ymai.fun**

---

## 怎么用

| 步 | 做什么 | 用什么 |
|---|---|---|
| 🟢 1 | 让 AI 帮你做一件小事（写一段自己的话） | 豆包 |
| 🔵 2 | 让 AI 帮你做出一个真东西（网页/文章/PPT 大纲） | 豆包 |
| 🟣 3 | 遇到问题自己找答案，还会核实靠不靠谱 | DeepSeek |
| 🟠 4 | 让现成工具替你干重复活（整理资料/处理 PDF） | 豆包 + Stirling PDF |

全部免费开始、国内直接打开、手机可用、不用 API Key。
第 4 步的 Stirling PDF 需要电脑，没有可以先跳过，文字内容用豆包/DeepSeek 一样处理。
