# World Space

> 我们不制造能力，我们寻找世界上已经存在的最好能力，然后帮助普通人知道：我想做这件事，该从哪里进去、怎么开始、怎么把它做出来。

**公开入口：https://ymai.fun**

---

## 这是什么

World Space 帮助普通人找到并使用世界现有优秀能力，把一个想法真正开始做起来。

打开 ymai.fun，选一个方向，几分钟后就知道该从哪里开始。

---

## 仓库结构

```
PRODUCT.md              唯一产品定义

index.html              根跳转页

docs/design/            唯一设计真源

```
