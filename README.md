# World Space

> 帮助一个普通人把一个真实想法带进现实。

World Space 是 MingOS 三条生命产品线之一：

| 产品线 | 仓库 | 核心 |
|---|---|---|
| 我和自己 | YuemingHub/Return-to-oneself | 理解自己、形成真实意图 |
| 我和家庭 | YuemingHub/Family-Space | 人与最重要关系中的真实共同生活 |
| **我和世界** | **YuemingHub/World-Space** | **把一个真实想法带进现实** |
