## 1. 产品形态

单页行动入口（纯静态，单文件 HTML）：

```
sticky topbar（品牌 + 总进度 x/3 + 进度条；进度条仅在兜底路径有进度后显示）
→ hero（「你想做什么事？」+ 7 个目标按钮 + 1 个兜底宽按钮）
   └─ 7 个目标按钮 → 按需展开目标面板（写点东西 / 做个网页 / 查明一件事 / 整理资料·处理 PDF / 做一张海报 / 整理手机照片 / 提取图片文字）：
        每个面板按真实子目标给一个默认能力 + 第一步（可复制）+ 做到什么算开始 + 卡住怎么办 + 如实标注
        写：豆包模板句 + 改稿循环（首次登录提示；初稿事实需自己过目；文章/总结/自我评价/PPT 大纲/发言稿同一招）
        网页：豆包对话生成预览；进阶「发布上线」→ v0（免费能开始，用量大了要付费）
        查：DeepSeek 深度思考 + 联网搜索 + 文件拖进输入框上传（免费已核证；隐私先删再传）+ 30 秒核实清单（官方渠道确认钱/政策；要签的合同找律师把关+12348 免费法律咨询热线）；副标题覆盖「翻译文件」
        资料/PDF：乱文字→豆包整理（微信语音长按转文字复制过来）；录音转文字→通义听悟（免费 90 天、每天 2 小时，官方文档核证；要登录、90 天后收费如实标注）；PDF 文件→Stirling PDF（需电脑；手机替代路径如实标注）；隐私（证件号/银行卡号）先删敏感部分再发 AI
        海报：准确信息→稿定设计模板改字；个人用（生日邀请、家庭聚会、节日祝福图）→豆包 AI 生图（含复制模板句；每天免费次数有限如实标注）
        照片：去重（iPhone/安卓原生+「合并不是清空相册」安心话+iOS 老系统如实拆分）、备份（自带云/一刻相册）、印刷相册（照片书小程序）、修图（醒图）
        OCR：微信长按提取文字、相册自带识别（iPhone 实况文本/安卓）、纸质用微信扫一扫；复制后可粘贴给豆包讲解/翻译/改写
   └─ 兜底宽按钮「不知道从哪开始？跟着三步走」→ 进入完整路径
→ 自述标题「第一次用 AI？跟着三步走」
→ 1 张阶段卡（手风琴）「三步上手：做成、改好、查证」：
    阶段引言（一段话，不占步骤）
    → 3 个编号步骤（手风琴）：① 豆包做一件小事（含登录如实提示 + 不会打字走豆包 App 语音）② 让它改成你满意的样子 ③ 查一件事并核实
    → 阶段检查点（把用户交回首页目标按钮）
→ 完成画面（做成的事清单 + 指向目标按钮 + 分享）
```

一次只展开一个阶段、一个步骤、一个目标面板；完成即自动折叠并展开下一步。目标面板独立于兜底路径的进度体系。兜底 2026-09-11 由 4 阶段 9 步收缩为 1 阶段 3 步（与目标面板重复的 7 步删除）。

## 2. 设计 Token（与 `web/index.html` :root 一致）

| Token | 值 | 用途 |
|---|---|---|
| `--accent` | `#3B82F6` | 阶段徽章数字底、状态 pill 底色 |
| `--accent-strong` | `#2563EB` | 主操作/工具按钮背景、链接 |
| `--leaf` | `#16A34A` | 完成/生长、进度条、徽章 |
| `--sun` | `#D97706` | 第 4 阶段徽章 |
| `--bg` | `#FAF9F6` | 页面背景（暖纸白） |
| `--surface` | `#FFFFFF` | 卡片面 |
| `--fg` | `#111827` | 主文本 |
| `--fg-muted` | `#6B7280` | 次文本 |
| `--border` | `#E7E5E0` | 描边 |

半径：12px（卡片）/ 6px（小件）。阶段徽章用 `--leaf`（前景深化 #166534 满足 WCAG AA）。主按钮与工具按钮背景用 `--accent-strong`（白字 5.17:1；`a.tool-btn` 特异性需高于 `.step-body a` 链接色），完成类按钮与复制成功态用 `#15803D`（白字 5.02:1），徽章数字 19px bold（大文本 3:1 档）。`--sun` 与 `--accent` 仍为 token（前者当前无阶段可挂，保留备用）。

## 3. 字体与排版

- 系统字体栈：`-apple-system, 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif`，0 外部字体请求
- 正文 17px / 行高 1.8；h1 `clamp(24px, 5vw, 34px)`；步骤标题 16px；辅助文字 14–15px
- 内容列最大宽 680px

## 4. 交互与无障碍

- 手风琴聚焦：当前阶段/步骤展开，其余折叠；完成自动折叠 + 滚动到下一步
- `prefers-reduced-motion` 停用全部动画
- 移动端（≤480px）触控目标 ≥44px：复制按钮与检查点按钮 `min-height: 44px`，工具按钮 14px×28px padding
- 标题语义：阶段标题 h2、步骤标题 h3、完成画面 h2
- 复制：`navigator.clipboard` → `execCommand` fallback（微信内置浏览器等）
- 外链一律 `target="_blank" rel="noopener"`

## 5. 性能约束

单文件 HTML（CSS/JS 全内联），0 外部请求（无字体/图标/JS/CSS 依赖），无构建步骤。 emoji 作为轻量图标语言，不引入图标库。
