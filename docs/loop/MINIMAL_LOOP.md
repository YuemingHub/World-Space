## 为什么重做

线上现行版本是「7 个目标按钮 + 兜底三步」。它的价值已经被验证（能替人判断、能给第一步），
但它是一个**目录**：用户进来选一个，出去做完，故事就结束了，我们不知道他做没做成、卡在哪。

这一版改成**一条回路**，四拍走完：

```
① 真实意图  →  ② 世界资源  →  ③ 行动  →  ④ 反馈
   用户自己说      只给一个默认      给第一步      做没做成/卡在哪
   想做成什么      能力 + 如实标注   做到算开始     交回给 Founder
```

## 四个环节的具体约定

| 环节 | 做什么 | 不做 |
|---|---|---|
| ① 真实意图 | 一句话自由输入，变成"意图卡"（可复制、可回改） | 不靠自建词典猜意图（2026-09-11 typed-door 已否决：误指路是最坏失败） |
| ② 世界资源 | 只给 **1 个**默认能力 + 「为什么是它」+「如实说」限制 | 不摆多个让用户挑；不做资源大全 |
| ③ 行动 | 每步：做什么 / 做到什么算开始 / 卡住怎么办 / 做完了 ✓ | 不写课程、不设关卡、不讲解 |
| ④ 反馈 | 二选一（做成了 / 卡住了）→ 卡在哪一步 → 生成一句可复制的话 | 不上报服务端、不埋统计、不索要联系方式 |

## 技术形态（零后端）

- 单文件静态 HTML（CSS/JS 全内联），**0 外部请求**，无构建、无依赖、无后端。
- 意图、进度、反馈全部只写 `localStorage`（key `ws_loop_state`），清浏览器数据即消失。
- 反馈靠"生成一句话 → 用户自己复制 → 发给 Founder"，**不上报任何服务器**，页脚已如实声明。
- 沿用现行设计 token 与无障碍基线（暖纸白、移动端触控 ≥44px、`prefers-reduced-motion`、
  复制按钮含 `execCommand` fallback）。

## 上线方式（不破坏现有站点）

- `v2` 分支不参与 GitHub Pages 构建（Pages 只发布 `main` 根目录），因此现在的线上站点**完全不受影响**。
- 本机预览：直接用浏览器打开 `web/index.html`（`file://` 即可，页面不联网）。
- 正式上线：把本分支合并进 `main` → Pages 自动重建 → `https://ymai.fun` 根路径换成本版。
  回滚：`git revert` 该合并提交即可回到现行版本。
