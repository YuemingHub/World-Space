# 目标覆盖判断（Goal Coverage）

> 本文是「首页为什么是这 7 个目标、什么该进来、什么明确不进来」的常设判断记录。
> 不追求数量。新目标进入首页的唯一通道：通过 §16 七问 + 本文分类更新。
> 最后研究：2026-09-11

## 判定规则（一句话）

**如果这件事最好的现成能力都要付费、装 App 或注册，普通人也不会因为它来 World Space。**
反之：能力免费可开始 + 目标高频真实 + World Space 能明显减少试错 → 才值得一个入口。

## 当前 7 个目标（全部 COVERED）

写点东西 / 做个网页 / 做一张海报 / 整理手机照片 / 查明一件事 / 整理资料·处理 PDF / 提取图片文字。

## 2026-09-11 目标扫描结论

| 真实目标 | 分类 | 判断 |
|---|---|---|
| 群消息/乱资料整理成清单 | COVERED | 整理资料面板（豆包，聊天记录已列为示例） |
| 长政策文件看不懂 | COVERED | 查明一件事面板（粘贴+大白话+核实清单） |
| 看懂合同 | PARTIALLY_COVERED | 工具同上，但重大合同应找律师——若做面板必须带此 caveat；暂不单独做 |
| 回复孩子/领导的一句话 | COVERED | 写点东西面板 |
| 今晚要一张邀请图/促销图 | COVERED | 海报面板（两种情况已二分） |
| 周末旅行规划 | COVERED（无需入口） | 「问豆包/DeepSeek」即可，面板化不增加价值 |
| 比较两台冰箱 | COVERED（无需入口） | 同上，查明一件事模式 |
| 视频里的话变成文字 | UNSERVED——暂不进入 | 剪映识别字幕已转会员付费（2026-09-11 核查）；手机自带不稳定；第三方网站未过验证。缺免费可靠默认 → 七问不通过 |
| 会议录音整理 | UNSERVED——暂不进入 | 自带录音机转文字仅部分机型；小程序/免费 App 未过隐私与免费验证。同上 |
| 批量改文件名 | OUT_OF_SCOPE | 需要电脑+脚本思维，普通人频率低 |
| 自动化重复电脑工作 | OUT_OF_SCOPE | n8n 级工具属进阶，保留在 catalog 不进首页 |

## 重开触发器

- 出现免费、国内直开、无需注册的语音/视频转文字默认能力 → 重估「转文字」入口
- Founder 观察到真实用户反复提出的、上表之外的目标 → 直接按 §55 提级
