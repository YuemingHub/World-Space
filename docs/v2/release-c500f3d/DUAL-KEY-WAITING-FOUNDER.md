## 1. 你要的效果，代码已经能做到了

```text
配置方法（两种都行）：
  WS_SEARCH_KEY=钥匙1,钥匙2
  WS_SEARCH_KEY=钥匙1
  WS_SEARCH_KEY_2=钥匙2          ← 更好写的第二种

行为：
  先用第 1 把；只有这把"本身不行"才自动换第 2 把 ——

  网络断开、请求超时、Tavily 自己 500/503
  → 换一把也一样失败；换了反而把"断网了"伪装成"我们已经自愈"，
    排查时会把人带偏到钥匙上去
```
