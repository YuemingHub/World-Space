## 2. 裁决小结

- **true P1：2 条**（S1-d 未问发证机构；S4-c 未问内容存量）——都是"该问但没问"，不是编造，也不是问卷化。
- **evaluator false-positive：6 条**（S1 / S2-d / S2-e / S3-e / S4-a / S5-e）——全部是被子串判据误杀。
- **uncertain：4 条**（S3 / S5-a / S6 / S6-e）——变量确实没问，但按当前动作层级不是必须，留待用户回答后再判。

另有两处旧 evaluator 的误报一并记账：

- 「给了路径但没有任何可追溯资源」3 条（S2-d / S2-e / S6-e）：这 3 条路径是**纯过程建议**
  （"先过医生评估这一关，再谈行程"），没有断言任何外部事实，按契约本来就不需要证据绑定。
  evaluator v2 已把它降级为候选，并且只在"本轮确实有可用证据"时才判 P1。
- 「资源全是 AI 软件」整轮空转：本轮 resources 恒为 0（无搜索 provider），该判据无从触发。

## 3. Guard 观察（无证据模式）

- `path_revoked_no_evidence` 触发 6 条：在**没有搜索 provider** 的配置下，这是契约要求的正确行为
  （确定路径里的高风险判断没有证据支撑）。它是否属于 overreach，必须在**接入真实搜索之后**重测。
- `safe_action_neutralized` 本轮 0 条：上一轮修好的"动作不该被关键词闸门误杀"保持有效，
  6 条 case 的 `safe_action_kept_flagged` 说明动作被保留并标注了"需自己核实"。
