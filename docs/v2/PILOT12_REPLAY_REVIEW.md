## 2. 本轮修掉的真实失败（4 个）

1. **时区错误（runtime/factual）**：`today()` 用 UTC——每天 8 小时模型拿到"昨天"的日期、
   日额度在本地早 8 点才重置。已改本地日期。
2. **证据时效（evidence failure，F3 后续）**：S5-e 把 **2019 年卫健委网站转载的人民日报报道**
   （"延续护理入口"）当作现行入口，`official_primary` 徽章下完全没暴露时效。
   修法：guard 新增确定性时效旗标——高风险资源的证据发布时间较旧（URL/字段可提取年份 >3 年）
   或无法确认时，强制注入"口径是否现行请核对"。重放验证：2019 → 标注、2025 → 不标、无年份 → 标注。
3. **组合层保守（product failure）**：S1 有 8 条证据在手却 0 资源、纯自省式路径（本轮唯一自动 P1）。
   修法：compose 阶段指令加一句"可用证据里与下一步真正相关的应做成 resources"——这不是掩盖护栏，
   是产品主线（找到世界已有资源）的正向表达。S7 批次（改动后）4/5 触发搜索的条目都产出了资源。
4. **死链实时剔除（evidence failure，F3）**：S6 一条死链被存活检查**实时剔除**——
   首次在生产路径上生效。全程未误删（保守策略只认 404/410）。
