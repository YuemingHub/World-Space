# 发布提案 · AI 从零开始（World Space 第一条零基础入门线）

> 本文件是给 Owner 决策用的：**这份候选现在真实是什么、要靠什么证据相信它、点"上线"之前你必须决定什么。**

---

## 1. 一句话

在现有 `ymai.fun` / `YuemingHub/World-Space` 的静态站里，**新增**一个给完全不懂 AI 的人
（孩子与青少年是重点体验群体，成人初学者同样服务）的入口：先看懂 AI 能做什么、会在哪里出错，
再从三件小事里选一件**真的做出来**。

**没有改**首页、没有改域名路由、没有改部署配置、没有碰 Family Space / Self Space、没有读任何真实用户数据。

## 6. 未完成 / 仍然 Unknown（不遮掩）

1. **真实用户验证 = 0**。所有"零基础的人看得懂"的说法，都是 reviewer 的角色扮演阅读，**不是真人**。
   这是第 1 阶段的真实状态；按 `PRODUCT.md` §9，A1/A2/A3 的最终判据要靠真人第一次使用。
2. **豆包/DeepSeek 登录后的免费范围无法核实**：不登录抓不到官方价目，页面因此只引用官方可见原话
   （"登录即可免费使用"）并明确写"额度与价格不写"。
3. **年龄口径是官方条款，不是我们的执行能力**：我们无法验证工具侧如何执行 18 岁门槛；页面如实引用条款原文与链接。
4. **发布路径未打通**：`ymai.fun` 现在实测 302 → `/login`（v2 应用服务器，非静态根），
   新页面在这个候选里**没有对外地址**，只能本地预览或直接从 GitHub 读源码。这不是缺陷，是授权边界。
5. **没有运营主体 / ICP / 联系方式**：正式对公网发布前的硬门槛，需要 Owner 决定主体与备案路径。
6. **新站与旧首页是"并存"关系**：从新站能回旧站，但旧站**没有**入口指向新站（本阶段刻意不改旧首页）。
   要不要让新站成为默认首页 / 加一个入口，是产品决策。

## 7. 需要 Owner 决定的事（发布前，按顺序）

1. **发布形态**：`/ai/` 作为并列入口（旧首页不变），还是逐步替换 `ymai.fun/` 的默认首页？
   两条路的区别：并列 = 零风险、但用户可能到不了；替换 = 用户能到、但要动现有首页与部署。

5. **真人验证怎么做**：找 1 个孩子 + 1 个成人初学者各走一条路径，记录他们卡住的句子——这是 A1–A3 唯一的最终判据。
