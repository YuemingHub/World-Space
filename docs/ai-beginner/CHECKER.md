# AI 从零开始 · 独立复验（Checker 专用说明）

> 这一页不是给作者看的，是给**独立复验者**看的：你要用什么方式、复跑哪些命令、按什么标准判它行不行。
> 你的结论不需要和作者一致；你只需要让每个结论都能被第三个人复跑。

## 1. 先确认你审的是什么

```powershell
cd <本仓库检出目录>
git rev-parse HEAD
git status --short
```

记录：提交 SHA、是否有未提交改动、你开始与结束的时间。**历史绿灯不算证据**，只有你在当前 HEAD 上跑出来的结果算。

## 2. 三种打开方式（都不需要安装任何东西）

| 方式 | 命令 / 操作 | 用途 |
|---|---|---|
| 直接打开文件 | 用 Chrome 打开 `web/ai/index.html` | 零依赖，功能完整（纯静态） |
| 本地预览（零依赖） | `node scripts/preview.mjs`，然后访问 `http://127.0.0.1:4173/ai/`（静态根=`web/` 形态）与 `http://127.0.0.1:4173/web/ai/`（静态根=仓库根形态） | 验证两种部署根下站内链接都成立 |
| 线上（若 Owner 已批准发布） | `https://ymai.fun/ai/` 或 `https://ymai.fun/web/ai/` | 只在发布后才有；**未发布时这两条地址 404 是正常事实**，不要据此判断产品好坏 |

## 3. 作者自测（你必须亲自复跑，不能用作者的报告当证据）

```powershell
node eval/ai-beginner-selftest.mjs          # 内容契约，零依赖；期望 EXIT 0
node eval/ai-beginner-journey.mjs           # 真实浏览器旅程
```

`ai-beginner-journey.mjs` 需要两样本机已存在的东西，绝不下载：

- `playwright-core`：默认路径 `C:/Users/User/AppData/Local/npm-cache/_npx/e41f203b7505f1fb/node_modules/playwright-core`（可用 `PW_CORE` 环境变量覆盖）；
- 本机 Chrome（脚本用 `chromium.launch({ channel: 'chrome' })`，**不要**执行 `npx playwright install`，本机下载会失败）。

可选参数：

```powershell
$env:BASE_URL="http://127.0.0.1:4173"; $env:SITE_DIR="/ai"; node eval/ai-beginner-journey.mjs
```

截图与机读报告落在 `var/ai-journey/<时间戳>/`（`var/` 已在 `.gitignore` 中，不入库）。

## 4. 你要独立回答的问题（不要接受作者的自评）

| # | 问题 | 判 P0 的标准 |
|---|---|---|
| 1 | 首屏（手机 390x844、桌面 1440x900）能不能在 5 秒内让一个不懂 AI 的人说出「这是什么、先点哪」 | 说不出之一 |
| 2 | 完全不会编程的人，能不能不询问他人就找到「第一步」 | 需要再点 3 次以上、或走进死胡同 |
| 3 | 三条路径是否都能从头走到「做成」判据，且判据是**现实里看得见的结果** | 任一判据退化成「打开了网站」 |
| 4 | 页面上的工具事实（可达性、免费范围、年龄）今天是否成立；有没有编造的数字/案例 | 引导孩子做危险或错误的事；必用链接打不开 |
| 5 | 未成年人是否被要求提供任何个人信息；「不要告诉 AI 什么」是否够用 | 出现任何收集个人信息的字段 |
| 6 | 320 / 390 / 768 / 1440 是否横向溢出；交互元素可点区是否 ≥44px；字号是否可读 | 有横向滚动或点不中 |
| 7 | 旧站（`web/index.html`、根 `index.html`）的入口与交互有没有被改坏 | 任一旧入口失效 |
| 8 | 页面是否真的 0 第三方请求（无统计、无字体、无 CDN） | 出现任一第三方请求 |
| 9 | 未成年人边界：页面是否鼓励把孩子/家人的照片或现实信息发到公开处 | 出现鼓励性措辞 |

## 5. 结论格式

每个发现写：**观察到的原文或截图路径 → 你实际做的操作 → 结论（P0/P1/P2）→ 建议的最小修法**。
没有证据的直觉写「未验证」，不要写成结论。最后给一句总判：**可以给 Owner 看 / 修完再看 / 不该上线**。
