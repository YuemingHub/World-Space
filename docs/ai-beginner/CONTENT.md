> 一页看清「谁可以改什么、改的时候必须守住什么」。
> 页面的**内容真源就是页面本身**（纯静态 HTML，无数据层）。本文件只负责导航与约束，不复制页面文案，避免出现第二份真源。

## 2. 事实纪律

1. **每条工具事实都必须有实测证据**：状态码/跳转落点/页面原文片段，落在 `evidence/` 或 PR 的检查记录里。没有证据就不写「免费」「可达」「最低年龄」。
2. **官方条款优先**：「官方条款未明确」是允许的结论，编一个年龄数字不允许。
3. **复核日期永远留着**：`tools.html` 与首页页脚都写明「复核于 2026-10-31」，到期前（90 天）复核，改完更新日期。
4. **不虚构**：没有用户数、没有成果、没有转化率、没有「已有多少人学会」。整站目前 0 统计数据，这是刻意的。
5. **A/B 结论不写进页面**：还没被真实用户检验过的假设，写在 `docs/ai-beginner/PRODUCT.md` 的计划里，不写在孩子会读到的页面里。

## 3. 页面语言约定

- 面向 10–15 岁能读懂，成人不觉得幼稚：句子短，主句在前，术语第一次出现必须有一句人话解释。
- 不用「赋能 / 闭环 / 心智 / 陪伴式成长」这类词；不用「你可以成为更好的自己」这类空话。
- 每个「你应该做什么」后面必须跟着「做到什么算成」。
- 任何失败都要给下一个具体动作，不评价人（写「换一个更简单的题目」，不写「你可能不太适合」）。

## 4. 评判这次改得好不好（给下一位接手者）

不看截图好不好看，看四件事：

1. 一个零基础的人能不能在 5 秒内说出「这是什么、先点哪」；
2. 三条路径是不是都能走到一个**现实里看得见的结果**；
3. 交付的每一条工具事实是不是**今天仍成立**；
4. 有没有为了「好看」而让孩子多填一个字段、多暴露一个信息。

前三条任何一条不成立，就不该上线；第四条出现任何一次，就该回退那次改动。
