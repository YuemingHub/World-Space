## 1. ⚠️ 先说一个必须核对的事实：任务书描述的是线上 v2，不是这条分支

任务书 §0 说本站「内容全部堆在一张网页里」「emoji + 卡片墙」。那是**生产分支 `v2`**
（nginx→:3200→`server/world.mjs`，未登录 `GET /` 还会 302 到 `/login`）上的样子。
本轮施工基线 `design/ming-language-20260919` 上，卡片墙与 emoji 在上一轮（2026-09-19）
就已经换成 MING 骨骼的行式入口了。所以本轮真正的增量是：

- 把首屏从「hero + 六个解释屏 + 入口」收成「hero + 入口」；
- 把每个入口内部从「一次全展开」改成**三层**；
- 把「不知道从哪开始？」从入口列表里挪出来，默认完全不展开；
- 抽屉换成 `<details>`。

`web/index.html` 与 `v2` 的那一份差异 1104 插入 / 533 删除——**这一轮的东西要让人看见，
必须先解决 ymai.fun 的 302 与 v2 cutover**，那是后端 + nginx 的活，见
`docs/YMAI-FUN-FRONTDOOR-HANDOFF.md`（别的会话写的交接文档，本轮未动）。

## 2. 页面：默认看到什么 / 点什么才展开 / 展开是什么

```
World Space（顶栏 + 开口圆）
        World Space  我和世界
          你想做什么事？              ← 唯一 H1，「什么事？」用门外天光绿
          选一件，先做第一步。
  ────────────────────────────────
  写点东西          把要说的事说清楚，几秒拿到一版初稿，再说哪里改。   →
  做个网页          不用学编程：说清楚要什么，它直接做出来给你看效果。 →
  查明一件事        要查就查得可靠：找真实信息、带来源，然后花 30 秒核实。→
  整理资料 · 处理 PDF  乱文字让 AI 归类；PDF 文件用桌面工具处理，文件不上网。→
  做一张海报        先分一件事：图上要不要放准确的信息？两条路不一样。 →
  整理手机照片      去重、备份、印成一本相册、把照片修好看——四件不同的事。→
  提取图片文字      不用装任何 App：微信和手机自带就能做。按图在哪分三条。→
  ────────────────────────────────
  不知道从哪开始？  跟着三步走。约 10 分钟…                      →
  这里是做什么的？                                              →
```

七个真实入口**全部留在第一屏**（用户来这里就是做事，不能把入口藏起来）；藏起来的是解释。

**点开一项（第二层）**只看到三样：`现在最简单的做法`（一两句）+ `第一步`（一句可直接复制的话）
+ `打开工具 →`（`.entry` 那颗按钮，直接跳出去）。
**再点（第三层）**才有「为什么选这个？」「还要注意什么？」——其他选择、进阶工具、限制、风险、
「以对方页面为准」那类实话，全在第三层。
「整理手机照片」「提取图片文字」这两项没有单一工具可打开，第二层给的是「先挑你最想做的这一件」
+ 四枚 / 三枚子选择，各自再点开。

**「不知道从哪开始？」**默认完全不展开；点开才进三步（做成 → 改好 → 查证），
三步内容原样保留，没有扩成 4 阶段 9 步，也没有重新造课程。

合上以后：文档高度 1902 → 1902（差 0px）。
