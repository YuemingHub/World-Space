# Fixture B · 虚构公开音频 → 转写 / 摘要

> 全虚构，无真实录音、无真实个人数据（`DATA_BOUNDARY.md` §4）。
> 音频由本机 TTS 合成（edge-tts，微软公开端点，无 key、无生产凭据），内容是我们自己写的句子。
> 脚本 `make_fixture_b_audio.py` 可本地重跑；原始输出在 `out/fixture_b_asr_output.txt`。

---

## 1. 输入

喂给 TTS 的原句（Ground truth）：

```text
这是一段虚构的测试音频。本月三号，我借给张伟八千三百元。
另外买了两袋水泥，花了一百零三点五元。
联系电话是一三八零零一三一零零八。记着，零是零，不是字母欧。
```

故意埋的易错点：

```text
8/3              "八千三百"（8300）与"三号"
中文数字 vs 阿拉伯数字   口述是中文数字，用户要的是能用的数字
0/O              "零是零，不是字母欧"
长数字串          "一三八零零一三一零零八"（13800131008）
小数点           "一百零三点五"（103.5）
同音             零 / 欧
```

## 2. 能力

```text
本地 ASR：sherpa-onnx + paraformer 中文模型（int8），纯离线，无外部请求
音频：16kHz 单声道 16bit WAV，时长约 17 秒
```

本机没有 ffmpeg / 没有系统 TTS，用的是 pip 装的 `edge-tts` 与 `imageio-ffmpeg` 的 ffmpeg。
证据等级：**Machine Evidence**（不是普通人在手机上用的那个 App）。

## 3. 结果

转写输出：

```text
这是一段虚构的测试音频本月三号我借给张伟八千三百元另外买了两袋水泥花了一百零三点五元
联系电话是一三八零零一三一零零八记着零是零不是字母哦
```

对这个输出做 `/\d+/` 提取阿拉伯数字：

```text
（无）
```

## 4. 错误形态

| # | 形态 | 例子 |
|---|---|---|
| 1 | **标点全丢** | 所有句号、逗号消失，成一段连读文字 |
| 2 | **同音字替换** | "不是字母**欧**" → "不是字母**哦**" |
| 3 | **数字保持中文形式** | 八千三百 / 一百零三点五 / 一三八零零一三一零零八 |

第 3 条不是"识别错"，字一个都没错。但它决定了这份转写**能不能直接用**。

## 5. 错误是否显眼

| 形态 | 显眼吗 | 后果 |
|---|---|---|
| 标点丢失 | 显眼 | 读起来累，但不影响信息 |
| 欧 → 哦 | **不显眼** | 原句是"0 不是字母 O"的教学句，转写后变成"不是字母哦"，语义被换掉了，但句子仍然通顺 |
| 中文数字 | 显眼（看得到"八千三百"） | 但要改成 8300 得再转一道；用户**想录入表格时**才发现不可用 |

## 6. Verification 方法（普通人现实可行吗）

| 方法 | 能抓到什么 | 可行性 |
|---|---|---|
| 回听对照 | 全部能抓 | 可行，但**等于把录音重听一遍**——正是用户想省掉的力气 |
| 关键数字回读（把"八千三百"念回原音频核对） | 抓数字错误 | 可行，但只覆盖他**想起来要核**的那几个 |
| 用第二个引擎交叉比对 | 能抓同音字 | 普通人不会做，也没有第二个引擎 |
| 结构化校验（手机号 11 位、金额量级） | 需要先做中文→阿拉伯数字转换 | 转换这一步本身就会出错 |

## 7. Operator 结论

```text
能力层：TECHNICAL_FEASIBILITY
观察层：OPERATOR_OBSERVATION
```

- **TECHNICAL_FEASIBILITY**：本地 ASR 把整段话都说全了，字级准确（唯一错字是同音的"欧/哦"）。
- **OPERATOR_OBSERVATION**：这是三个 fixture 里最"成功也最没用"的一个——
  **转写完成了，但产出物不能直接当数据用**：

```text
没有标点 → 不能分段
数字是中文 → 不能粘进表格
同音字被替换 → 语义陷阱句被改掉，而且改得通顺
```

用户真正想要的是 `8300`、`103.5`、`13800131008`。他得到的是"八千三百""一百零三点五"。
中间那一步（中文数字 → 可用数字）**没有人负责**，而这正是 §5 分类里 `TRANSLATION`
或 `VERIFICATION` 的位置。

**不得输出 `ORDINARY_REACHABLE`。**

## 8. 一个诚实的边界

本 fixture 用的是**机器合成的标准普通话**，没有口音、没有环境噪声、没有多人说话。
真实会议录音（对应种子 S3）会难得多。本结果**不**外推到真实录音场景。
