你现在可以做到什么？

把那些你每天/每周重复做的事情，用工具自动跑。比如"收到邮件→自动存到表格→发消息通知"。

n8n →

要钱吗？

  • Stirling PDF：开源免费（桌面版/自部署）
  • n8n：自部署免费但有技术门槛；Cloud 有免费试用（具体价格以官网为准）

第一步

处理 PDF（Stirling PDF）

  • 打开 stirling.com，下载桌面版（免费）
  • 选择你要的操作（合并 / 拆分 / 压缩 / 转换）
  • 上传文件，点执行

自动化工作流（n8n）

  • 打开 n8n.io，注册 Cloud 试用
  • 点"Create Workflow"
  • 添加一个触发器（比如"每天早上 8 点"）
  • 添加一个动作（比如"调用 AI 总结邮件"）
  • 连起来，激活
触发器：每天早上 8 点 动作：调用 AI 总结昨天的邮件 动作：把总结发到我的微信/飞书

做到什么算第一步成功？

  • Stirling PDF：你成功合并/拆分/压缩了一个 PDF
  • n8n：你的第一个工作流成功跑了一次，自动完成了一件以前要手动做的事

卡住了怎么办？

问题解决
n8n 不知道怎么开始先看官方模板库，找一个接近你需求的复制改
n8n 连不上某个应用检查该应用是否需要 API Key 或授权
不确定要不要用 n8n如果你只是偶尔手动操作一次，不需要自动化。n8n 适合每周重复 3 次以上的任务
