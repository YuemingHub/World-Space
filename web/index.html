你看到一个能打开的网页，上面有你写的内容，布局合理。

写文章、做演示、画图、整理知识——现在都有了最省事的起点。

不管你是想写一篇文章、做一份演示、画一张图，还是把零散的想法整理清楚，都有不用学就能上手的工具。

Gamma：输入主题，AI 自动生成演示结构 + 视觉。比 PPT 省时间十倍。不用排版。

Excalidraw：打开网页就能画，不用注册，不用安装。手绘风格，让普通人也有表达自信。

要钱吗？

  • Notion：免费够用；Plus $10/月
  • Gamma：免费额度可用；Plus $10/月

少做一些重复工作

自动整理、自动收集、批量处理——让工具替你跑重复步骤。

你现在可以做到什么？

把那些你每天/每周重复做的事情，用工具串起来自动跑。比如"收到邮件→自动存到表格→发消息通知"。

最推荐从哪里开始？

看你要做什么：

  • 串联多个工具自动跑 → n8n
  • 处理 PDF 文件 → Stirling-PDF
n8n → Stirling-PDF →

为什么推荐它们？

n8n：全球最流行的开源自动化工具之一。可视化拖拽，不用写代码。连接 400+ 应用。Cloud 版免安装。

Stirling-PDF：强大的 PDF 工具箱。合并、拆分、压缩、转换，全部免费。在线版直接用，也可以自己部署保护隐私。

难不难？

Stirling-PDF：非常简单，打开网页上传文件就行。

n8n：中等。需要理解"触发器→动作"的概念，但不需要写代码。

要钱吗？

  • n8n：自部署免费；Cloud 从 €20/月
  • Stirling-PDF：在线版/自部署免费

第一步

处理 PDF（Stirling-PDF）

  • 打开 stirlingpdf.com
  • 选择你要的操作（合并 / 拆分 / 压缩 / 转换）
  • 上传文件，点执行

不需要注册，不需要安装。

自动化工作流（n8n）

  • 打开 n8n.io，注册 Cloud 试用（或自部署）
  • 点"Create Workflow"
  • 添加一个触发器（比如"收到邮件"）
  • 添加一个动作（比如"存到 Google Sheets"）
  • 连起来，激活
触发器：每天早上 8 点 动作：调用 AI 总结昨天的邮件 动作：把总结发到我的微信/飞书

做到什么算第一步成功？

  • Stirling-PDF：你成功合并/拆分/压缩了一个 PDF
  • n8n：你的第一个工作流成功跑了一次，自动完成了一件以前要手动做的事

卡住了怎么办？

问题解决
n8n 不知道怎么开始先看官方模板库（Templates），找一个接近你需求的复制改
n8n 连不上某个应用检查该应用是否需要 API Key 或授权
Stirling-PDF 处理大文件慢在线版有大小限制，大的文件建议自部署
不确定要不要用 n8n如果你只是偶尔手动操作一次，不需要自动化。n8n 适合每周重复 3 次以上的任务
