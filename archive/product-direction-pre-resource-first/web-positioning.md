## 2. 新信息架构

### 旧架构（v2 评估）

```
看见 → 学会 → 陪跑
```

问题：把 World Space 做成了教程网站 + 陪跑服务。陪跑是服务不是产品。

### 新架构

```
看见 → 试一试 → 做出来
```

| 幕 | 目标 | 用户感受 |
|---|---|---|
| **看见** | 让人相信"普通人也能把想法变成现实" | "这件事我也能做" |
| **试一试** | 让人迈出第一步，输入一个真实想法 | "我有一个想法，试试看" |
| **做出来** | 进入 World Space，走完从想法到现实的全过程 | "我真的做出来了" |

### 陪跑的位置

陪跑是可选服务，不是产品本体。如果需要，放在"做出来"之后的尾部，作为"需要帮助的人可以申请陪跑"。不在主路径上。

## 4. 首页结构（调整后）

```
hero
  主张：你想让什么事情发生？
  副文：一个普通人，也能把脑海里的想法变成看得见的现实。
  主 CTA：我有一个自己的想法
  次 CTA：先看看别人做了什么

看见区
  信念对比 + 示例故事（保留 v1 故事卡形式，标注"示例"）
  核心感受：这件事我也能做

试一试区
  一个输入框：你想让什么事情发生？
  输入后 → 进入 World Space（创建 Reality Project）
  这不是教程，是邀请

做出来区（World Space 预览）
  简要展示 Reality Project 的样子
  意图 → 定义结果 → 下一步 → Artifact → Evidence → 完成
  让人看到"做出来"长什么样

尾部
  可选：需要帮助？可以申请陪跑（占位）
  页脚
```
