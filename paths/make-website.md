# 第一阶段 · 新手村：认识 AI，跟它说上话

> 所有人从这里开始。约 5 分钟。知道 AI 是什么，能帮你干什么。

---

## 1. AI 到底是什么？

用大白话说：AI 就是一个读过很多很多书的助手。你问它问题，它帮你回答；你让它写东西，它帮你写。

它不像搜索引擎那样只给你链接，而是直接给你写好的答案。

但要记住：它会出错。它不是万能的。

## 2. AI 能帮你做什么？

- 写东西 — 朋友圈文案、文章、邮件、自我介绍
- 做东西 — 网站、PPT、海报
- 找答案 — 查资料、对比、解释概念
- 处理文件 — 合并 PDF、压缩、转换格式
- 翻译 — 中英互译

## 3. 打开豆包，说第一句话

豆包（doubao.com）是字节跳动做的 AI 助手。就像微信聊天一样，你说一句，它回一句。

✅ 国内直接打开 ✅ 全中文界面 ✅ 免费 ✅ 不用注册也能聊

打开后把这段话复制进去，发送：

```
帮我写一段朋友圈文案，介绍我今天做的一件事，
语气轻松一点，100字左右。
```

## 4. 再多试几句，感受一下

不用怕说错，随便聊。你会发现，它就像一个什么都知道一点的朋友。
