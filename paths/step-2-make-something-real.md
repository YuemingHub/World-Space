# 第二步 · 让 AI 帮你做出一个真东西

> 约 15 分钟。网页、文章、PPT 大纲，做出来能给人看。不用换工具。

## 1. 让豆包帮你做一个网页

豆包不只会聊天——跟它说"帮我做一个网站"，它真的能做出来。就用刚才那个豆包。

先复制：
```
帮我做一个个人介绍网页。
顶部写我的名字。
下面放一段自我介绍。
然后放一个我做过的事情列表。
最下面留联系方式。
整体风格简洁好看。
做好后直接显示预览效果。
```
打开豆包，粘贴发送。它会直接在对话里显示网页效果；只看到代码就说"显示预览"。不满意直接说哪里要改。

## 2. 让豆包帮你写一篇文章

```
帮我写一篇短文，讲讲我最近在忙什么，
语气像在跟朋友聊天，500字左右。
```

## 3. 让豆包帮你做一份 PPT 大纲

```
帮我做一份演示文稿大纲，讲讲我最近做的事，
大约8页，每页有标题和内容要点。
风格简洁。
```
豆包生成的是文字大纲，可以拿着在 WPS 或 PowerPoint 里做成可翻页的演示文稿。

做到这里：你有一个能拿给人看的东西了。
