# 第三阶段 · 第二关：让 AI 帮你找答案

> 约 10 分钟。查资料、找答案，而且知道答案靠不靠谱。

---

## 1. 认识 DeepSeek：比豆包更会"思考"

DeepSeek（chat.deepseek.com）— 国产 AI，免费，中文。两个豆包没有的能力：
- 深度思考 — 先想一会儿，再给更详细的回答
- 联网搜索 — 去网上找真实信息，告诉你答案从哪来的

## 2. 问一个真问题

先复制：
```
我想了解一下，做副业卖东西一般从哪里开始？
我没什么经验，请用大白话解释。
```
打开 DeepSeek，找到"深度思考"开关打开它（输入框下方，变蓝色。找不到也没关系）。粘贴发送。

## 3. 让 AI 联网搜索最新信息

打开"联网搜索"开关，先复制：
```
2026年适合个人开网店的平台有哪些？
请对比它们的费用和门槛。
```
粘贴发送。DeepSeek 会标注信息来源，你可以点进去核实。

## 4. ⚠️ AI 会出错

有来源链接的 → 点进去看。涉及钱的 → 去官方确认。感觉不对的 → 换个工具再问一遍对比。
