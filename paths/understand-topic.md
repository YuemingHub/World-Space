# 我想搞明白一件事情

> 查资料、深度研究、对比、找证据——现在有免费的 AI 帮你。

---

## 你现在可以做到什么？

你不用翻几十个网页自己拼凑信息。用 AI 对话或搜索，直接得到带来源的答案。

## 最推荐从哪里开始？

**DeepSeek**（https://chat.deepseek.com）

如果你需要带来源引用的深度研究，用 **Perplexity**（https://perplexity.ai）。

如果你要读论文，用 **GPT-Academic**（https://github.com/binary-husky/gpt_academic）。

## 为什么推荐它们？

### DeepSeek
免费、中文好、有深度思考模式、国内可直接访问。不需要翻墙，不需要 API Key。对中文用户来说是最省事的 AI 入口。

### Perplexity
专注"带来源的搜索+研究"。每个答案都有出处链接，不是凭空生成。适合需要核实信息的研究场景。

### GPT-Academic
专为学术场景优化：一键论文总结、翻译、润色。支持多种模型。中文社区活跃。适合学生和研究者。

## 难不难？

- DeepSeek：非常简单，跟聊天一样
- Perplexity：非常简单，跟搜索一样
- GPT-Academic：中等，需要安装和配置 API Key

## 要钱吗？

- DeepSeek：完全免费；API 价格极低
- Perplexity：免费额度可用；Pro $20/月
- GPT-Academic：开源免费；需要自己的 API Key

## 第一步

### 日常问答 / 查资料（DeepSeek）
1. 打开 https://chat.deepseek.com
2. 打开"深度思考"开关
3. 问你的问题

第一句怎么说：
```
我想了解一下，做手工艺品在网上卖，一般从哪里开始？
我不懂电商，请用大白话解释。
```

### 深度研究（Perplexity）
1. 打开 https://perplexity.ai
2. 输入你的研究问题
3. 看答案下面的来源链接，点进去核实

第一句怎么说：
```
2025年最适合个人手工艺者开店的电商平台是哪些？
请对比它们的费用、流量、入驻门槛。
```

## 做到什么算第一步成功？

你得到了一个有依据的答案，并且知道这个答案的来源是什么。

## 下一步怎么走？

1. 答案不够？追问细节
2. 想交叉验证？换一个工具再问同样的问题
3. 需要引用？把来源链接记下来

## 卡住了怎么办？

| 问题 | 解决 |
|---|---|
| DeepSeek 回答太笼统 | 打开"深度思考"模式，或者在问题里加"请详细分析" |
| Perplexity 国内打不开 | 用 DeepSeek 替代，或者用科学上网工具 |
| 答案跟我知道的不一样 | AI 会出错。重要信息一定要看来源链接，自己核实 |
| GPT-Academic 安装太复杂 | 先用 DeepSeek。GPT-Academic 适合经常读论文的人再装 |
