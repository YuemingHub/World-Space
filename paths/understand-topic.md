# 我想搞明白一件事情

> 查资料、深度研究、找证据——现在有免费的 AI 帮你。

---

## 你现在可以做到什么？

你不用翻几十个网页自己拼凑信息。用 AI 对话，直接得到答案。

## 先从这里开始

**DeepSeek**（https://chat.deepseek.com）

免费、中文好、有深度思考模式、国内可以直接访问。不需要翻墙，不需要 API Key。

需要带来源引用的深度研究可以用 Perplexity（https://perplexity.ai），但国内可能无法直接访问。如果打不开，先用 DeepSeek。

## 要钱吗？

- DeepSeek：免费
- Perplexity：可以免费开始（具体价格以官网为准）

## 第一步

### 日常问答 / 查资料（DeepSeek）
1. 打开 https://chat.deepseek.com
2. 打开"深度思考"开关
3. 问你的问题

第一句怎么说：
```
我想了解一下，做手工艺品在网上卖，一般从哪里开始？
我不懂电商，请用大白话解释。
```

## 做到什么算第一步成功？

你得到了一个有依据的答案，并且知道这个答案的来源是什么。

## 下一步怎么走？

1. 答案不够？追问细节
2. 想交叉验证？换一个工具再问同样的问题
3. 需要引用？把来源链接记下来

## 卡住了怎么办？

| 问题 | 解决 |
|---|---|
| DeepSeek 回答太笼统 | 打开"深度思考"模式，或者在问题里加"请详细分析" |
| Perplexity 打不开 | 先用 DeepSeek。DeepSeek 也能联网搜索 |
| 答案跟我知道的不一样 | AI 会出错。重要信息一定要自己核实 |
