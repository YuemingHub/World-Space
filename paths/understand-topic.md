# 第二关：搞明白一件事

> 查资料、找答案、理解一个概念——免费、中文、国内直接打开。

---

## 用哪个？

**DeepSeek**（chat.deepseek.com）— 国产 AI，免费，中文好，能联网搜索，有深度思考模式。

✅ 国内直接打开 ✅ 中文界面 ✅ 免费 ✅ 能联网搜索 ✅ 有深度思考

## 第一步：问个问题

打开 DeepSeek，打开"深度思考"开关，把问题打进去：

```
我想了解一下，做手工艺品在网上卖，一般从哪里开始？
我不懂电商，请用大白话解释。
```

## 想搜索最新信息？

打开"联网搜索"开关，再问：

```
2026年适合个人手工艺者开店的平台有哪些？
请对比它们的费用和门槛。
```

DeepSeek 会搜索网上的真实信息，然后总结给你。

## 做到什么算通关？

你得到了一个有依据的答案，而且知道这个答案是从哪来的。

## 重要提醒

AI 会出错。重要信息一定要自己核实。比如 AI 说"某平台免费"，你去那个平台确认一下。

## 还有别的选择

- **Kimi**（kimi.moonshot.cn）— 擅长读长文章、长文档。如果你有一份很长的资料想理解，用 Kimi。
- **豆包**（doubao.com）— 日常问答也很好用，和新手村是同一个工具。

## 卡住了？

| 问题 | 解决 |
|---|---|
| 回答太笼统 | 打开"深度思考"模式，或者在问题里加"请详细分析" |
| 答案好像不对 | AI 会出错。重要信息自己核实，别全信 |
| 想读一份很长的 PDF | 用 Kimi（kimi.moonshot.cn），它能读很长的文档 |
