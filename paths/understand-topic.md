# 第三阶段 · 第二关：让 AI 帮你找答案

> 约 10 分钟。查资料、找答案，而且知道答案靠不靠谱。

---

## 1. 认识 DeepSeek：比豆包更会"思考"

DeepSeek（chat.deepseek.com）有两个豆包没有的能力：
- 深度思考 — 它会先想一会儿，再给你更详细的回答
- 联网搜索 — 它会去网上找真实信息，告诉你答案从哪来的

✅ 国内直接打开 ✅ 全中文 ✅ 免费

## 2. 问一个真问题

打开"深度思考"开关（在输入框下方，打开后变蓝色。找不到也没关系，不开也能用），然后问：

```
我想了解一下，做副业卖东西一般从哪里开始？
我没什么经验，请用大白话解释。
```

## 3. 让 AI 联网搜索最新信息

打开"联网搜索"开关，再问：

```
2026年适合个人开网店的平台有哪些？
请对比它们的费用和门槛。
```

DeepSeek 会先去网上搜真实信息，然后帮你总结。每个答案都标注来源。

## 4. ⚠️ AI 会出错，怎么判断答案靠不靠谱

- 有来源链接的 → 点进去看一眼
- 涉及钱、政策、法律的 → 一定要去官方渠道确认
- 感觉不太对的 → 换个工具再问一遍，对比两个答案
- 太具体的数据 → 可能是编的，自己查
