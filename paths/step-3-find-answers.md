# 第三步 · 遇到问题，自己找到答案

> 约 10 分钟。不光得到答案，还知道它靠不靠谱。

## 1. 用 DeepSeek 认真问一个问题

日常聊天、做东西，豆包就够。要认真查一个问题，用 DeepSeek（chat.deepseek.com）：会先想一会儿再回答（深度思考），还能联网搜索。✅ 免费 ✅ 中文 ✅ 国内直接打开。

先复制：
```
我想了解一下，做副业卖东西一般从哪里开始？
我没什么经验，请用大白话解释。
```
打开"深度思考"开关（找不到也没关系），粘贴发送。

## 2. 让 AI 联网搜索最新信息

打开"联网搜索"开关，先复制：
```
2026年适合个人开网店的平台有哪些？
请对比它们的费用和门槛。
```
DeepSeek 会标注信息来源，你可以点进去核实。

## 3. ⚠️ AI 会一本正经地说错话

有来源链接的 → 点进去看。涉及钱的 → 去官方确认。感觉不对的 → 豆包和 DeepSeek 各问一遍，对比答案。

做到这里：你自己查到了答案，还知道它从哪来。
