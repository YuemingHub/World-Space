# 第一关：做个东西出来

> 用一个国内工具，说一句话就能做出真的东西——网站、PPT、文章都行。

---

## 用哪个？

**扣子**（coze.cn）— 字节跳动做的 AI 办公平台。一个工具就能做网站、PPT、文章、图片。

✅ 国内直接打开 ✅ 中文界面 ✅ 能做网站、PPT、文章、图片 ✅ 注册就能用

## 做一个网站

打开扣子后，找到输入框，把下面这段话发进去：

```
帮我做一个手工作品展示网站。
顶部写网站名字"我的手工作品"。
下面放一段自我介绍。
然后放一个作品展示区，每个作品有图片和名字。
最下面留联系方式。
整体风格温暖简洁。
```

扣子会帮你生成一个网页。你能看到它、改它、发布它。

## 做一份 PPT

同样是扣子，换个要求：

```
帮我做一份关于"我的手工作品"的演示文稿，
大约8页，每页一个作品，带介绍。
风格温暖简洁。
```

## 写一篇文章

如果你只是想写东西，也可以直接让扣子帮你：

```
帮我写一篇关于"我为什么开始做手工"的短文，
语气像在跟朋友聊天，500字左右。
```

## 做到什么算通关？

你做出了一个能看的东西——网站、PPT、或文章。能给别人看，就算通关。

## 下一步

不满意？直接跟扣子说哪里要改，比如"颜色换成暖棕色"或"加一个关于我的页面"。

## 卡住了？

| 问题 | 解决 |
|---|---|
| 扣子里找不到输入框 | 首页就有聊天框，直接打字就行 |
| 做出来的不像我要的 | 给更具体的要求。不要说"做好看点"，说"顶部用暖棕色，标题大一号" |
| 想改某个部分 | 直接说："把联系方式改成表单" |
| 想发布到网上 | 扣子生成的网页可以直接分享链接 |
