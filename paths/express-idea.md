# 第二阶段 · 第一关：做出一个真东西

> 新手村里你只是聊天。这次，你要用 AI 做出一个能给别人看的东西。

---

## 用什么？

**扣子**（coze.cn）— 也是字节跳动做的。豆包只能聊天，扣子能帮你做出真的东西：网站、PPT、文章。

✅ 国内直接打开 ✅ 全中文界面 ✅ 一个工具做网站+PPT+文章 ✅ 手机也能用

## 做个网站（最推荐先试这个）

打开扣子，找到输入框，把这段话发进去：

```
帮我做一个手工作品展示网站。
顶部写网站名字"我的手工作品"。
下面放一段自我介绍。
然后放一个作品展示区，每个作品有图片和名字。
最下面留联系方式。
整体风格温暖简洁。
```

等一会儿，扣子会帮你生成一个网页。你能看到它，也能改它。

## 做一份 PPT

同样在扣子里，换个要求：

```
帮我做一份关于"我的手工作品"的演示文稿，
大约8页，每页一个作品，带介绍。
风格温暖简洁。
```

## 写一篇文章

```
帮我写一篇关于"我为什么开始做手工"的短文，
语气像在跟朋友聊天，500字左右。
```

## 做到什么算通关？

你做出了一个能看的东西——网站、PPT 或文章。能给别人看，就算通关。

## 不满意？继续改

不用重新做。直接跟扣子说哪里要改：
- "把颜色换成暖棕色"
- "加一个关于我的页面"
- "标题大一号"

## 卡住了？

| 问题 | 怎么办 |
|---|---|
| 找不到输入框 | 首页就有聊天框，直接打字 |
| 做出来的不像我要的 | 说得更具体。别说"做好看点"，说"顶部用暖棕色，标题大一号" |
| 想发布到网上 | 扣子生成的网页可以直接分享链接 |
