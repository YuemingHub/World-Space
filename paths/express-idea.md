# 第二阶段 · 第一关：用 AI 做出一个真东西

> 约 15 分钟。用豆包做出网站、文章或 PPT 大纲。不用换工具。

---

## 1. 豆包不只会聊天，还能"做东西"

就跟它说"帮我做一个网站"，它真的能帮你生成一个网页。不用换工具。

## 2. 让豆包帮你做一个网页

先复制：
```
帮我做一个个人介绍网页。
顶部写我的名字。
下面放一段自我介绍。
然后放一个我做过的事情列表。
最下面留联系方式。
整体风格简洁好看。
```
打开豆包，粘贴发送。豆包通常会在对话里直接显示网页效果。如果只看到代码，跟它说"显示预览"。

不满意？直接说哪里要改。

## 3. 让豆包帮你写一篇文章

先复制：
```
帮我写一篇短文，讲讲我最近在忙什么，
语气像在跟朋友聊天，500字左右。
```
打开豆包，粘贴发送。

## 4. 让豆包帮你做一份 PPT 大纲

先复制：
```
帮我做一份演示文稿大纲，讲讲我最近做的事，
大约8页，每页有标题和内容要点。
风格简洁。
```
打开豆包，粘贴发送。豆包生成的是文字大纲，你可以拿着在 WPS 或 PowerPoint 里做成可翻页的演示文稿。
