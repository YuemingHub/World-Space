## 1. 处理 PDF：下载一个免费软件就够

Stirling PDF（stirling.com）— 免费桌面软件。合并、拆分、压缩、转换 PDF，全部免费，不用联网。

✅ 完全免费 ✅ 支持中文 ✅ 下载到电脑用，保护隐私

打开官网后找到下载按钮。网站是英文的，但安装后软件是中文的。
Windows 选 .exe 或 .msi，Mac 选 .dmg。

## 2. 把 AI 用起来：整理资料、总结文件

回到豆包或 DeepSeek，先复制：
```
我有一份资料内容很乱，帮我整理成三部分：
现状、主要选择、给我的建议。
```
粘贴发送。几秒出结果，不用自己花半小时整理。

什么时候才需要自动化？每周重复 3 次以上的事才值得。
