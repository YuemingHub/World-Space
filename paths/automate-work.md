# 我想少做一些重复工作

> 自动整理、批量处理——让工具替你跑重复步骤。

---

## 你现在可以做到什么？

把那些你每天/每周重复做的事情，用工具自动跑。比如"收到邮件→自动存到表格→发消息通知"。

## 先从这里开始

- **处理 PDF 文件** → Stirling PDF（https://stirling.com）
- **串联多个工具自动跑** → n8n（https://n8n.io）

## 为什么推荐它们？

### Stirling PDF
强大的 PDF 工具箱。合并、拆分、压缩、转换，全部免费。桌面版免费下载（Windows/macOS/Linux），也可以自己部署。

### n8n
可视化拖拽，不用写代码，连接 400+ 应用。Cloud 版免安装。自己使用或用 Cloud 可以直接开始；如果准备拿它做商业产品，需要另外看授权。

## 要钱吗？

- Stirling PDF：开源免费（桌面版/自部署）
- n8n：自部署免费但有技术门槛；Cloud 有免费试用（具体价格以官网为准）

## 第一步

### 处理 PDF（Stirling PDF）
1. 打开 https://stirling.com，下载桌面版（免费）
2. 或注册在线版
3. 选择你要的操作（合并 / 拆分 / 压缩 / 转换）
4. 上传文件，点执行

### 自动化工作流（n8n）
1. 打开 https://n8n.io，注册 Cloud 试用
2. 点"Create Workflow"
3. 添加一个触发器（比如"每天早上 8 点"）
4. 添加一个动作（比如"调用 AI 总结邮件"）
5. 连起来，激活

第一个工作流示例：
```
触发器：每天早上 8 点
动作：调用 AI 总结昨天的邮件
动作：把总结发到我的微信/飞书
```

## 做到什么算第一步成功？

- Stirling PDF：你成功合并/拆分/压缩了一个 PDF
- n8n：你的第一个工作流成功跑了一次，自动完成了一件以前要手动做的事

## 下一步怎么走？

1. Stirling PDF：尝试更多功能（加水印、OCR、压缩）
2. n8n：加更多步骤，让工作流更智能

## 卡住了怎么办？

| 问题 | 解决 |
|---|---|
| n8n 不知道怎么开始 | 先看官方模板库，找一个接近你需求的复制改 |
| n8n 连不上某个应用 | 检查该应用是否需要 API Key 或授权 |
| 不确定要不要用 n8n | 如果你只是偶尔手动操作一次，不需要自动化。n8n 适合每周重复 3 次以上的任务 |
