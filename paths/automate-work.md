# BOSS关：少做重复活

> 这关有点挑战。但一旦设置好，以后就不用再手动重复了。

---

## 两个方向，选一个

- **处理 PDF 文件**（合并、拆分、压缩、转换）→ Stirling PDF，下载桌面版就能用
- **串联多个工具自动跑**（比如收到邮件自动存到表格）→ n8n 或 WorkBuddy

## 处理 PDF（简单）

**Stirling PDF**（stirling.com）— 免费下载的桌面软件。合并、拆分、压缩、转换，全部免费。

✅ 免费 ✅ 中文界面 ✅ 下载到电脑用，不用联网

打开后选你要的操作（合并/拆分/压缩/转换），上传文件，点执行。就这么简单。

Windows 选 .exe，Mac 选 .dmg。

## 自动化工作流（有挑战）

**WorkBuddy**（workbuddy.cn）— 腾讯出的 AI 办公助手，能自动完成报告、表格等任务。

✅ 国内直接打开 ✅ 中文界面

**n8n**（n8n.io）— 连接 400+ 应用的自动化工具。适合想搭工作流的人。

⚠️ n8n 界面是英文的。需要理解"触发器→动作"的概念，但不需要写代码。

## 做到什么算通关？

你成功处理了一个 PDF，或者你的第一个自动化工作流跑通了。

## 卡住了？

| 问题 | 解决 |
|---|---|
| 不确定要不要用自动化 | 偶尔手动做一次的事不需要自动化。每周重复3次以上才值得 |
| n8n 不知道怎么开始 | 先看官方模板库，找一个接近你需求的复制改 |
| Stirling 下载哪个版本 | Windows 选 .exe，Mac 选 .dmg |
