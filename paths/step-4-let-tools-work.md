# 第四步 · 让现成工具替你干重复活

> 约 10 分钟。整理资料、处理 PDF，不用事事自己来。

## 1. 让 AI 帮你整理资料

乱七八糟一堆资料，自己整理要半小时，AI 几秒就搞定。回到豆包，先复制：
```
我有一份资料内容很乱，帮我整理成三部分：
现状、主要选择、给我的建议。
以下是需要整理的内容：
（在这里粘贴你的资料）
```
把"（在这里粘贴你的资料）"换成你自己的内容——会议记录、长文章、零散笔记都行。

## 2. 处理 PDF：装一个免费软件（需要电脑）

Stirling PDF（stirling.com）— 免费桌面软件。合并、拆分、压缩、转换 PDF，全部免费，不用联网，文件不上传。

✅ 完全免费 ✅ 支持中文 ✅ 下载到电脑用，保护隐私
