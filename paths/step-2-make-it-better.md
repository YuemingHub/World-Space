# 第二步 · 让它改成你满意的样子

> 约 3 分钟。会提要求，AI 才真正好用。

刚才那段话，多半还不是你愿意直接发出去的样子。这一步才是真本事：把不满意的地方直接说给它听。

## 1. 把不满意的地方说给它听

复制这句，换成你真实的意见：

```
把你刚才写的改一下：太长了，短一半；
语气再轻松一点，像在跟朋友说话。
结尾加一句问大家的问题。
```

不用推倒重来——它会在原来的基础上改。继续提要求，直到那段话你真的愿意用。

💡 这招通用于所有事：网页「标题大一号」、海报「换个颜色」、文章「例子再具体一点」。要做网页、海报、整理照片这些具体的事，回到首页点对应的按钮，第一步都替你写好了。

做到这里：你手里有一段自己改过、愿意直接用的话。
